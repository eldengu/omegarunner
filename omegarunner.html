Three experts (same model, different system prompts), each a forward+inverse pair. Inverse = propose an action; forward = predict the next state for each action. The executed action is the responsibility-weighted vote; then every expert's forward model is scored on the same executed action and responsibility λ = softmax(−error/σ²) flows to whoever predicts reality best. The right column shows each expert's forward-prediction error (hover for the running average that drives λ).
